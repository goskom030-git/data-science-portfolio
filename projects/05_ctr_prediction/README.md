# Прогнозирование кликабельности рекламы (CTR Prediction)

## 📌 Краткое описание проекта
Оценка вероятности клика по рекламному объявлению. Калибровка вероятностей (Probability Calibration), обработка анонимизированных признаков, борьба с экстремальным дисбалансом, сохранение производственного пайплайна.

---

## 🛠 Стек технологий
* **Направление:** AdTech / Marketing
* **Задача:** Бинарная классификация вероятности клика при сильном дисбалансе классов
* **Технологии и библиотеки:** `Python, Scikit-learn, LightGBM, CalibratedClassifierCV, Joblib`
* **Достигнутые метрики:** **PR-AUC: 0.68, ROC-AUC: 0.83**
