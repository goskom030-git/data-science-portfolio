# Прогнозирование кликабельности рекламы (CTR Prediction)

## Описание проекта
Оценка вероятности перехода по рекламным объявлениям. Калибровка вероятностей (Probability Calibration), обработка анонимизированных признаков, работа в условиях сильного дисбаланса, сохранение пайплайна в joblib.

---

## Стек технологий и параметры
* **Домен:** AdTech / Marketing
* **Задача:** Бинарная классификация вероятности клика при дисбалансе классов
* **Технологии:** `Python, Scikit-learn, LightGBM, CalibratedClassifierCV, Joblib`
* **Метрики качества:** **PR-AUC: 0.68, ROC-AUC: 0.83**
