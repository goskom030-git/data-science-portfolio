# Прогнозирование спроса на городской велопрокат

## 📌 Краткое описание проекта
Исследование нелинейных зависимостей спроса на городской велопрокат от климатических условий (температура, влажность, скорость ветра, осадки). Оптимизация kNN и деревьев решений с кастомной метрикой расстояний.

---

## 🛠 Стек технологий
* **Направление:** Smart City / Mobility
* **Задача:** Регрессия количества арендованных велосипедов с учётом погодных факторов
* **Технологии и библиотеки:** `Python, Scikit-learn (kNN, DecisionTree), Pandas, Seaborn`
* **Достигнутые метрики:** **MAE: 4.87, R²: 0.91**
