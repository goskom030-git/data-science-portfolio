# Анализ данных и статистическая проверка гипотез сервиса кикшеринга

## 📌 Краткое описание проекта
Исследование поведения пользователей сервиса аренды самокатов GoFast. Проверка статистических гипотез о длительности поездок, выручке от подписчиков и расчёт критической дистанции через квантили нормального распределения.

---

## 🛠 Стек технологий
* **Направление:** Urban Mobility / Micromobility
* **Задача:** Исследовательский анализ и проверка гипотез о поведении пользователей с подпиской
* **Технологии и библиотеки:** `Python, SciPy (ttest_ind, norm.cdf, norm.ppf), Pandas, Matplotlib`
* **Достигнутые метрики:** **Statistical Tests, Distribution Analysis (CDF/PPF)**
