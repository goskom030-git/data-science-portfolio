# Статистический анализ данных и проверка гипотез кикшеринга

## Описание проекта
Анализ поведения пользователей сервиса проката самокатов GoFast. Проверка статистических гипотез о длительности поездок, доходности пользователей с подпиской и расчёт критической дистанции через квантили распределения.

---

## Стек технологий и параметры
* **Домен:** Urban Mobility / Micromobility
* **Задача:** Исследовательский анализ и проверка гипотез о поведении пользователей
* **Технологии:** `Python, SciPy (ttest_ind, norm.cdf, norm.ppf), Pandas, Matplotlib`
* **Метрики качества:** **Статистические тесты, Расчёт квантилей (CDF / PPF)**
