# Выявление рисков задержки курьерской доставки

## 📌 Краткое описание проекта
Анализ логистических цепочек и построение классификатора для выявления заказов с высоким риском задержки. Генерация пространственных и временных признаков, анализ загруженности складов и курьеров.

---

## 🛠 Стек технологий
* **Направление:** E-commerce / Logistics
* **Задача:** Прогнозирование опозданий заказов для превентивного реагирования
* **Технологии и библиотеки:** `Python, CatBoost, Scikit-learn, Pandas, Seaborn, Feature Engineering`
* **Достигнутые метрики:** **ROC-AUC: 0.81, F1: 0.71**
