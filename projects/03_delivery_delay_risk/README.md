# Выявление рисков задержки курьерской доставки

## Описание проекта
Анализ логистических данных и построение классификатора для выявления заказов с риском срыва сроков. Генерация пространственных и временных признаков, учёт загруженности логистических узлов.

---

## Стек технологий и параметры
* **Домен:** E-commerce / Logistics
* **Задача:** Прогнозирование задержек заказов для превентивного реагирования
* **Технологии:** `Python, CatBoost, Scikit-learn, Pandas, Seaborn, Feature Engineering`
* **Метрики качества:** **ROC-AUC: 0.81, F1: 0.71**
