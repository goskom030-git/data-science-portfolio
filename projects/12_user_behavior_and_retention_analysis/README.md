# Исследование пользовательского поведения и факторов удержания (Яндекс.Афиша)

## Описание проекта
Комплексный анализ транзакционной истории и поведения пользователей сервиса Яндекс.Афиша. Проект направлен на выявление факторов, определяющих повторные покупки (retention), профилирование аудитории, расчет когортных метрик и поиск ключевых точек оттока.

---

## Стек технологий и параметры
* **Домен:** E-commerce / Entertainment & Events / Retention Analytics
* **Задача:** Профилирование пользователей, когортный анализ, корреляционный анализ факторов лояльности ($\phi_K$)
* **Технологии:** `Python, SQL, PostgreSQL, Pandas, NumPy, SciPy, Matplotlib, Seaborn, Phik`
* **Ключевые результаты:** Построены профили пользователей, выявлены критические интервалы для реактивации, определена структура влияния первого заказа на LTV
