# Модель прогнозирования биометрических параметров (Регрессия)

## 📌 Краткое описание проекта
Построение высокоточной регуляризованной модели регрессии (Ridge) для предсказания массы по линейным промерам панциря. Сравнение функций потерь (MAE vs MSE в SGD) и корреляционный анализ мультиколлинеарности.

---

## 🛠 Стек технологий
* **Направление:** Biology / Ecology / Sensor Data
* **Задача:** Точная оценка массы по морфометрическим измерениям
* **Технологии и библиотеки:** `Python, Scikit-learn (Ridge, Lasso, SGD, LinearRegression), Seaborn`
* **Достигнутые метрики:** **MAE: 3.63 kg, R²: 0.983**
