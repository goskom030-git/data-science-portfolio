# Модель регрессии биометрических параметров

## Описание проекта
Построение регуляризованной модели регрессии (Ridge) для предсказания массы по линейным промерам. Анализ мультиколлинеарности и сравнение функций потерь (MAE vs MSE в SGD).

---

## Стек технологий и параметры
* **Домен:** Biology / Sensor Data
* **Задача:** Оценка массы по морфометрическим измерениям
* **Технологии:** `Python, Scikit-learn (Ridge, Lasso, SGD, LinearRegression), Seaborn`
* **Метрики качества:** **MAE: 3.63 kg, R²: 0.983**
