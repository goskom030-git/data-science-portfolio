# Прогнозирование оттока клиентов сервиса доставки

## Описание проекта
Выявление клиентов с высокой вероятностью отказа от подписки. Анализ профиля потребления, генерация признаков пользовательской активности, подготовка модели к интеграции в CRM-систему.

---

## Стек технологий и параметры
* **Домен:** FoodTech / Subscription Service
* **Задача:** Классификация оттока клиентов (Churn Prediction)
* **Технологии:** `Python, CatBoost, Scikit-learn, Optuna, Feature Engineering, Joblib`
* **Метрики качества:** **PR-AUC: 0.73, F1: 0.61**
