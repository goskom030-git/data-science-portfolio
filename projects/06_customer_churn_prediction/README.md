# Прогнозирование оттока клиентов сервиса подписки

## 📌 Краткое описание проекта
Выявление клиентов, планирующих отказаться от подписки на кофе. Анализ жизненного цикла клиента (LTV), генерация признаков активности потребления, подготовка модели к интеграции в CRM.

---

## 🛠 Стек технологий
* **Направление:** FoodTech / Subscription Service
* **Задача:** Классификация оттока клиентов (Churn Prediction)
* **Технологии и библиотеки:** `Python, CatBoost, Scikit-learn, Optuna, Feature Engineering, Joblib`
* **Достигнутые метрики:** **PR-AUC: 0.73, F1: 0.61**
