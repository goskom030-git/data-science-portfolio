# Определение возраста и демографии пользователей (Computer Vision / ML)

## Описание проекта
Пайплайн извлечения признаков и мультиклассовой классификации возрастных групп. Оптимизация нелинейных ядер SVC (rbf), устранение дисбаланса когорт и сохранение обученного пайплайна.

---

## Стек технологий и параметры
* **Домен:** Computer Vision / Retail
* **Задача:** Мультиклассовая классификация возрастных когорт
* **Технологии:** `Python, PyTorch / Scikit-learn, SVC (rbf kernel), Joblib`
* **Метрики качества:** **F1-Score: 0.70 (Baseline: 0.09)**
