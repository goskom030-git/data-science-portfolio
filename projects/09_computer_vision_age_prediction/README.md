# Определение возраста и демографии пользователей (Computer Vision / ML)

## 📌 Краткое описание проекта
Пайплайн извлечения признаков и мультиклассовой классификации возрастных когорт. Оптимизация нелинейных ядер SVC (rbf), борьба с дисбалансом возрастных групп и сохранение пайплайна в pickle/joblib.

---

## 🛠 Стек технологий
* **Направление:** Computer Vision / Retail / Media
* **Задача:** Классификация демографических сегментов и возраста пользователей
* **Технологии и библиотеки:** `Python, PyTorch / Sklearn, Feature Extraction, Scikit-learn, Joblib`
* **Достигнутые метрики:** **F1-Score: 0.70 (прирост с baseline 0.09)**
