# Дизайн, проведение и анализ результатов A/B-тестирования

## Описание проекта
Полный цикл A/B-эксперимента: расчёт размера выборки и MDE, проверка корректности сплитования на AA-данных, мониторинг метрик вовлечения и проверка статистической значимости результатов.

---

## Стек технологий и параметры
* **Домен:** Media / Streaming Apps
* **Задача:** A/B-тестирование рекомендательного алгоритма и вовлечения
* **Технологии:** `Python, SciPy, Statsmodels, Pandas, Bootstrap, Hypothesis Testing`
* **Метрики качества:** **Z-test, p-value < 0.05, Статистически значимый прирост +4.2%**
