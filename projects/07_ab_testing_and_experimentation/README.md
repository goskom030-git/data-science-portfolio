# Дизайн, проведение и анализ результатов A/B-тестирования

## 📌 Краткое описание проекта
Полный цикл A/B-эксперимента: расчёт размера выборки и MDE, проверка сплитования на AA-данных, мониторинг сходимости и итоговая статистическая проверка гипотез о доле успешных сессий.

---

## 🛠 Стек технологий
* **Направление:** Mobile Apps / Streaming / Media
* **Задача:** A/B-тест новой механики рекомендаций и вовлечения пользователей
* **Технологии и библиотеки:** `Python, SciPy, Statsmodels, Pandas, Bootstrap, Hypothesis Testing`
* **Достигнутые метрики:** **Z-test, p-value < 0.05, Statistically Significant Lift +4.2%**
