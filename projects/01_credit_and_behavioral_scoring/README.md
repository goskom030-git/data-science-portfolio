# Поведенческий скоринг клиентов банка (Credit Scoring)

## 📌 Краткое описание проекта
Разработка модели поведенческого скоринга действующих заёмщиков для прогнозирования просрочки 90+ дней в горизонте 12 месяцев. Объединение 8 таблиц транзакций и выписок без утечек во времени (time-series split), отбор признаков и оптимизация гиперпараметров через Optuna.

---

## 🛠 Стек технологий
* **Направление:** Fintech / Banking
* **Задача:** Бинарная классификация просрочки 90+ дней (Default Prediction)
* **Технологии и библиотеки:** `Python, CatBoost, Optuna, Scikit-learn, Pandas, Time-based Split`
* **Достигнутые метрики:** **ROC-AUC: 0.77, F1: 0.65**
