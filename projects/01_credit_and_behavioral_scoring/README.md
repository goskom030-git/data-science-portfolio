# Поведенческий скоринг клиентов банка (Credit Scoring)

## Описание проекта
Разработка модели поведенческого скоринга действующих заёмщиков для прогнозирования просрочки 90+ дней в горизонте 12 месяцев. Объединение 8 таблиц транзакций и выписок с учётом временной структуры (time-series split), отбор признаков и оптимизация гиперпараметров с помощью Optuna.

---

## Стек технологий и параметры
* **Домен:** Fintech / Banking
* **Задача:** Бинарная классификация просрочки 90+ дней (Default Prediction)
* **Технологии:** `Python, CatBoost, Optuna, Scikit-learn, Pandas, Time-based Split`
* **Метрики качества:** **ROC-AUC: 0.77, F1: 0.65**
