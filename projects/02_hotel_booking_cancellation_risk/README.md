# Прогнозирование отмены бронирований отелей

## Описание проекта
ML-модель для раннего выявления вероятности отмены бронирования номеров. Выгрузка данных из PostgreSQL, очистка аномалий, объединение таблиц по временным срезам (merge_asof), оценка экономического эффекта внедрения депозитной системы.

---

## Стек технологий и параметры
* **Домен:** Hospitality / TravelTech
* **Задача:** Классификация риска отмены бронирования и расчёт депозитов
* **Технологии:** `Python, LightGBM, CatBoost, PostgreSQL, Scikit-learn, Feature Engineering`
* **Метрики качества:** **ROC-AUC: 0.84, F1: 0.76**
