# Прогнозирование отмены бронирований отелей

## 📌 Краткое описание проекта
ML-модель для раннего выявления вероятности отмены бронирования клиентами. Реализована выгрузка из PostgreSQL, очистка аномалий, объединение таблиц по временным срезам (merge_asof), оценка экономического эффекта от внедрения депозитов.

---

## 🛠 Стек технологий
* **Направление:** Hospitality / TravelTech
* **Задача:** Классификация риска отмены бронирования и расчёт динамического депозита
* **Технологии и библиотеки:** `Python, LightGBM, CatBoost, PostgreSQL, Scikit-learn, Feature Engineering`
* **Достигнутые метрики:** **ROC-AUC: 0.84, F1: 0.76**
